# MiMatera3D

Sitio de [mimatera3d.com](https://mimatera3d.com): configurador de la matera para el auto, con vista 3D, precio en vivo y pedido por WhatsApp.

Es una página estática (HTML, CSS y JavaScript, con three.js desde jsDelivr). La vista 3D usa un modelo de vidriera simplificado: no incluye los archivos de impresión ni el mecanismo de encastre.

Para cambiar precios, colores u opciones, editá el bloque `CAT` dentro de `index.html`. El número de WhatsApp está en la constante `WHATSAPP`.
